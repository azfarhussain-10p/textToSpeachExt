TTS Extension Features

This extension provides comprehensive text-to-speech functionality with the following features:

  • Universal TTS: Select any text on any website and listen with natural voices
  • AI Explanations: Get intelligent explanations using Groq and Claude APIs
  • Cross-Browser Support: Works on Chrome, Firefox, Safari, and Edge
  • Multilingual: Support for 15+ languages including English, Urdu, Arabic, Spanish, French, German, Hindi
  • Accessibility: Full WCAG 2.1 AA compliance with keyboard navigation and screen reader support
  • Mobile Ready: Touch-optimized overlay with responsive design
  • Privacy-First: No data collection without explicit consent
  • Customizable: Adjustable voice speed, pitch, and volume settings
  • Keyboard Shortcuts: Quick access via customizable keyboard shortcuts
  • Theme Support: Light and dark mode compatibility

The extension uses modern web technologies including the Web Speech API for text-to-speech synthesis, ensuring compatibility across different browsers and operating systems.

Security is a top priority, with proper content sanitization and secure API key storage to protect user data and prevent XSS vulnerabilities.
